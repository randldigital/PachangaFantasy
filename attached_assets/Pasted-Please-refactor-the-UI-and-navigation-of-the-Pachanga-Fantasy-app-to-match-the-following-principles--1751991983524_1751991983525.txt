Please refactor the UI and navigation of the Pachanga Fantasy app to match the following principles:

🎯 High-Level Goals:
- Simplify navigation: minimize routes, maximize in-context actions
- Merge views: Match and League data should live under one unified League view
- Follow Biwenger-style UX patterns: tabbed layout, bottom nav on mobile, fast interactions
- Use shadcn/ui + Tailwind for all components
- Maintain dark mode and multilingual support (Spanish default)

---

📐 New Route Structure:

1. /login and /register
- Keep as is, styled with dark theme, shadcn/ui forms

2. /overview (Dashboard)
- Show:
  - League Cards (user is part of)
  - “Join League” and “Create League” buttons (top right)
  - Cards show: name, status, invite code, participants
- Responsive grid, cards styled with Tailwind + shadcn Card

3. /league/:id (Central interaction hub)
- This is the single main view per league
- Replace all separate match, lineup, history pages with sections here
- Use Tabs or Segmented Buttons for internal navigation:
  - 🟢 "Mi Alineación"
  - 🟢 "Clasificación"
  - 🟢 "Historial"
  - 🟢 "Tier List"
  - Optional: "Mis estadísticas"

🧱 Section Behavior (League View):

🔹 Match Context Header
- If there’s an active match:
  - Show date, participation button, teams (if assigned)
  - “Join Match” → toggles acceptance
  - “Lineup” → opens modal or scrolls to inline component
- If no match: show call-to-action for admin to create one

🔹 Mi Alineación
- If accepted in match:
  - Show lineup builder (5 players, budget cap)
  - Cards to select/deselect players, select captain
  - Budget bar + validation
- Else: show info on how to join

🔹 Clasificación
- Table showing total user points in league
- Highlight the current user (e.g. background or "(You)")
- Sortable columns: points, matches played, goals, etc.

🔹 Historial
- Show past matches in collapsible list or swipeable carousel
- Click → opens modal with match details (teams, stats, MVPs, lineup)

🔹 Tier List
- If voting phase is open:
  - Drag-and-drop or up/down ranking inline
  - Submit/reset buttons
- If closed: show average results and market values

---

📱 Mobile Experience Enhancements:
- Add fixed bottom navigation bar with 4 icons:
  - Alineación, Clasificación, TierList, Perfil
- Use icon buttons (`lucide-react`) and hide on desktop
- Collapse less-used sections for clarity

---

🛠️ Technical Requirements:
- Use shadcn/ui Tabs, Dialog, Button, Card, Table, Avatar, etc.
- Tailwind responsive utilities (mobile-first)
- Use TanStack Query to load data dynamically, with optimistic updates
- Support language switching (i18next) and theme toggling
- Clean file structure: `/pages/overview.tsx`, `/pages/league/[id].tsx`, `/components/league/*`

---

🧩 Behavior to replicate from Biwenger:
- No deep navigation: everything is sectioned inside `/league/:id`
- Always show current user info in rankings and selections
- Inline interactions: no redirecting to separate forms
- Feedback: toast messages, loading skeletons, “+3 GOL” animations for fun
- Animations for lineup saves, ranking changes, point updates

Please implement this UI/UX refactor with clean, modular React components and keep the user experience minimal, responsive and fast.

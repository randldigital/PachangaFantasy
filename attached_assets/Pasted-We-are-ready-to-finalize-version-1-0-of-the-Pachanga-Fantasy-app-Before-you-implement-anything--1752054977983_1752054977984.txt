🟢 Version 1.0 – Final Scope

✅ Already implemented and stable:
- User registration and login with JWT
- Private league creation and invite code system
- Users can add themselves as players
- Admin can create one active match per league
- Players can join the match
- Each user can create a lineup with 5 players and 1 captain
- Budget validation for lineups
- Stat reporting (goals, assists) by users after the match
- Admin manually verifies total goals (no cross-verification)
- Points calculated automatically (3pts goal, 2pts assist, 2x captain)
- Player and user leaderboards updated with points

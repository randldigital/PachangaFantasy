Please redefine and adapt the database to a scalable PostgreSQL database schema using Drizzle ORM for the Pachanga Fantasy app. 

🧩 Tech stack:
- PostgreSQL
- Drizzle ORM
- Node.js / Express
- This is a fantasy league web app where users join leagues, rank players, set lineups, submit match stats and votes, and earn points.

🎯 Design the schema to support:
- Current features (user registration, league creation, Tier List)
- Future features (matchmaking, lineups, player stats, voting, scoring, transfers)

📐 Tables to implement:

1. users:
  - id (PK), username, email, password_hash, role ('admin' | 'player'), created_at

2. leagues:
  - id (PK), name, invite_code (unique), admin_id (FK to users), created_at

3. league_participants:
  - user_id (FK), league_id (FK)
  - Primary key: (user_id, league_id)

4. players:
  - id (PK), name, league_id (FK), market_value (integer), created_by (FK to users)

5. tier_lists:
  - id (PK), league_id (FK), user_id (FK), player_order (integer[]), submitted_at

6. matches:
  - id (PK), league_id (FK), date, status ('open' | 'closed' | 'completed'), lineup_budget, created_by (FK)

7. match_participants:
  - match_id (FK), user_id (FK), status ('accepted' | 'declined' | 'pending')
  - Primary key: (match_id, user_id)

8. lineups:
  - id (PK), match_id (FK), user_id (FK), player_ids (integer[]), total_cost

9. stat_reports:
  - id (PK), match_id (FK), user_id (FK), goals, assists, verified_by (FK, optional)

10. votes:
  - id (PK), match_id (FK), user_id (FK), mvps (integer[]), flops (integer[]), submitted_at

11. scores:
  - user_id (FK), match_id (FK), points
  - Primary key: (user_id, match_id)

🛠️ Requirements:
- Use `drizzle-orm` best practices
- Set up foreign keys, constraints, default values, and enums where appropriate
- Create all schema files in a `/db/schema/` folder
- Add timestamp fields (created_at) where relevant
- Prepare for use in Express app and export the schemas

The schema must be modular, normalized, and designed to evolve with the app without breaking existing features. Please also generate seed scripts and initial migrations to set it up.

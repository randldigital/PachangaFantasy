Create a fullstack web application called "Pachanga Fantasy" using technologies compatible with Replit: 
- Backend: Node.js with Express, Replit DB or MongoDB Atlas for persistence
- Frontend: React (with Vite), using React Router for routing
- Authentication with JWT

🟡 Core functionality for MVP (version 0.1):
1. A user can register or log in (JWT-based auth).
2. A user with role "admin" can create a new league, which generates a unique invite code.
3. Other users can join a league by visiting a link or entering the invite code.
4. Once users have joined, each participant can rank other players using a Tier List (drag-and-drop or position-based).
5. When all users have submitted, the admin can "close" the Tier List phase. The backend then calculates each player’s market value based on average position, removing the highest and lowest outliers.
6. Users can then view players in the league with their assigned market values.

🟦 Backend structure (Express):
- Models:
  - User: username, email, password (hashed), role (admin/player), leagueId
  - League: name, inviteCode, createdBy, participants[]
  - Player: name, leagueId, marketValue
  - TierList: leagueId, userId, playerOrder[]
- Routes:
  - POST /auth/register — user registration
  - POST /auth/login — login, return JWT
  - POST /leagues — create new league (admin only)
  - POST /leagues/:inviteCode/join — join league
  - POST /players/:leagueId — admin creates player list for league
  - GET /players/:leagueId — get player list
  - POST /tierlist/:leagueId — submit player's Tier List
  - POST /tierlist/:leagueId/close — admin closes voting, backend calculates values

🟩 Frontend (React with Vite):
- Pages:
  - Register / Login (with token storage)
  - Create League / Join League
  - League Dashboard (view members, players)
  - Tier List page (submit order of players)
  - Final results page (market values)

🔧 Tech setup:
- Keep backend in `/server/` and frontend in `/client/`
- Use Vite to initialize the React frontend
- Use simple CSS or Tailwind (optional)
- Use localStorage for auth tokens
- Minimal styling; focus on functionality
- Use Replit DB if MongoDB Atlas is not possible

Please scaffold the folders, implement the backend routes and models, and build a working UI that connects to them. Make sure a user can go through the full flow: register → create/join league → rank players → see results.

Please implement the next major iteration (v0.2) of Pachanga Fantasy using PostgreSQL and Drizzle ORM. This version introduces matches, automated team assignment, lineups, stat reporting, and player ranking.

🧩 Core Features to Build:

1. Match Creation (Manual)
- Admins can create matches with: league_id, date, time, and lineup_budget
- Status: 'open', 'ready', 'completed'

2. Player Sign-Up + Auto Team Balancing
- Players can accept match invitations
- When enough players accept (e.g. 10), automatically split them into 2 balanced teams
- Balance based on `market_value` or future `playerRating`
- Store: match_teams = { teamA: [playerIds], teamB: [playerIds] }

3. Lineup Builder
- Each user selects 5 players for their lineup
- Lineup must not exceed match’s budget (e.g. 100 total value)
- Store in a `lineups` table: match_id, user_id, player_ids[], total_cost
- Only one lineup allowed per user per match

4. Stat Reporting + Verification
- After match completion, each participant enters: goals, assists
- The system randomly assigns another participant to verify their entry
- New table `stat_reports`: user_id, match_id, goals, assists, verified_by, verified_status
- Include endpoint to confirm or dispute another user’s report

5. Points Calculation + Ranking
- After verification, calculate:
  - +3 points per goal
  - +2 points per assist
  - +1 point for match victory
- Save in a `scores` table: user_id, match_id, points
- Add `/league/:id/ranking` endpoint to get cumulative league points

6. League Dashboard View
- Add a frontend dashboard view with:
  - Upcoming match (date, participants)
  - Players list with current values
  - League-wide ranking leaderboard
  - Button to access match details & lineup

💾 Backend Tech:
- PostgreSQL + Drizzle
- Use FK relationships and enums where needed
- Add `match_teams` as a JSONB field if easier than separate table

🧩 Frontend Notes:
- Match detail page → Join button, show balanced teams
- Lineup builder → budget counter, player picker
- Stat form (after match) → goals, assists, assigned verification target
- Ranking view → table of users sorted by total points

Keep it consistent with existing architecture and design (dark mode, multilingual, shadcn/ui).

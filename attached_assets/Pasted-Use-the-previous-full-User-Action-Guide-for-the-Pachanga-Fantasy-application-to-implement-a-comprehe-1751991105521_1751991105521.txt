🔧 Testing Objective:
Automate end-to-end and integration tests to verify that each interactive element (button, input, action) works as expected in real-world usage.

📦 Tech Stack:
- Backend: Vitest + Supertest (Express API)
- Frontend: Playwright (preferred for E2E testing with React + Vite)
- Use testing environments and mock DB if needed

🧪 Test Areas (based on routes):

1. Authentication Flows (/login, /register)
- Validate login with valid/invalid credentials
- Validate registration with valid/invalid data
- Check redirect to dashboard after login
- Check role selection updates user correctly

2. Dashboard (/)
- Test "Create League" and "Join League" buttons
- Ensure League Cards are clickable and route correctly

3. League Management
- Test creating a league, joining with invite code
- Verify visibility of "Create Match", "Tier List", "Add Myself as Player" based on role
- Check correct player list rendering

4. Tier List (/tierlist)
- Test drag-and-drop functionality with multiple players
- Submit rankings and verify market value calculation
- Test reset button clears UI
- Check auto-save triggers API update

5. Match System
- Test match creation with date and budget
- Test "Join Match" flow
- Verify automatic team assignment after enough participants
- Validate match status transitions properly

6. Lineups (/lineup)
- Test adding/removing players to/from lineup
- Test captain selection logic (single captain, double cost)
- Validate total cost logic blocks saving if over budget

7. Results and Rankings
- Verify points display for each player
- Test correct rendering of leaderboard after match
- Test match history linking to results

8. Global Actions
- Check navigation bar links, dropdowns, logout
- Test language switch (ES/EN) and dark/light theme toggle
- Test mobile nav responsiveness (menu toggle)

9. Validations & Feedback
- Check that required fields throw correct errors
- Confirm success/failure toasts show correctly
- Ensure loading states are applied during async calls

🧱 Implementation Tips:
- Create reusable test user and league data
- Use test-specific DB or mock DB
- Organize tests by feature (/tests/auth, /tests/league, etc.)
- Add `npm run test:e2e` and `npm run test:backend` commands

Please begin implementing these tests now, starting with authentication, league creation, and tier list flow.
